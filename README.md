# DVA
Code to compute differential velocity aberration (DVA) up to 3rd order in v/c. Computed for any position on the sky and for any velocity magnitude and direction. The code also includes a class to compute the velocity direction for an orbit.

In addition, I've added code for similating astrometric observations of a Black Hole Binary Gravitational Wave Background with a Roman-like telescope, with properties similar to the Galactic Bulge Time Domain Survey (GBTDS). The code simulates observations of guide and field stars, DVA from a circular Earth-like oribt, and instantaneous re-centering on the guide stars, for observations of six 0.53x0.53 degree fields, continuously observed over 15 minutes. Relative deflections of stars at each observation are measured, a linear solution for the effect of DVA and telescope re-pointing is (optionally) subtracted, and the (remaining) deflecitions are projected onto 4 orthonormal linear mode templates. The power spectrum of these deflections is then computed. This analysis can be found in the Roman_GWB_Simulation_5years_Uninterrupted.ipynb notebook.
