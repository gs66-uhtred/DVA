# DVA
Code to simulate an astrometric measurement of the gravitational wave background. Includes the mean systematic, differential velocity aberration (DVA) up to 3rd order in v/c. 

Notebooks simulate a Roman-like telescope, with properties similar to the Galactic Bulge Time Domain Survey (GBTDS). The code simulates observations of guide and field stars, DVA from a circular Earth-like oribt, and instantaneous re-centering on the guide stars, for observations of six 0.53x0.53 degree fields, continuously observed over 15 minutes, or in 6 70.5 day seasons across 5 years, repreating all fields in 12.1 minute cycles. Relative deflections of stars at each observation are measured, a linear solution for the effect of DVA and telescope re-pointing is (optionally) subtracted, and the (remaining) deflecitions are projected onto 4 orthonormal linear mode templates. The power spectrum of these deflections is then computed.
